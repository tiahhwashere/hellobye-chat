Download for Windows
HelloBye-Setup.exe · ~75 MB · Windows 10/11 (64-bit)
Latest version v1.5.5
How to run: Download the file and double-click it. It is a portable app, so no installation is needed. Windows may show a SmartScreen prompt the first time; click More info then Run anyway.

Updates: The app checks the website every 30 seconds. When a new build is deployed, a prompt appears in the middle of the screen telling you to download the new build. Clicking Download closes the app, removes the old PC app, and opens this page so you can install the fresh build. Your login and data are always kept.
